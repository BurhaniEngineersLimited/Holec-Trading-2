# holec_trading

Custom Frappe/ERPNext app for Holec's maize trading system.

Covers the custom-build modules from the design: Lot lifecycle (6-state
machine with enforcement), Cost Ledger, Charge Master, Buy Ticket, Rail
Routing Bands, and origin/storage lookups. Parties, Payments, and eTIMS
run on native ERPNext + the Navari app - not part of this custom app.

See `INSTALL.md` for setup steps.
